# Voyage review corrections — 15 September 2026

This release corrects the register's handling of completed rotations, port times,
missing commercial values, cargo exports and keyboard navigation.

- Fully departed rotations show `Rotation completed` and the final completed port.
  Their OPR workflow status and end-date review remain separate.
- Each displayed port shows arrival and departure dates. Fixed dates are ATA/ATD;
  unfixed dates are labelled planned. Required arrival times are not relabelled as
  verified ETAs. No report or physical position verification is implied.
- Unzoned EventLog dates retain their port-local clock time (LT). Explicit offsets
  are normalized to UTC. Voyage start/end *GMT fields remain UTC.
- Unknown currencies no longer default to USD. Missing counts and laycan fields
  are not turned into zero or a negative registration finding. Explicit
  `cargo.laycanRegistered` false/true/null distinguishes registration when collected.
- Cargo descriptions export even when no laycan has been collected.
- Tab/Shift+Tab cycle through the drawer's actual links and buttons. Escape closes
  it and restores the previous focus.
- The shared OAuth function is exported with a default fetch implementation, so
  `fetch-operational.mjs` can actually import and use it.
- Projection refuses ambiguous/invalid call dates or an entirely missing date
  feed before replacing the previous snapshot. Writes use a temporary file and
  rename. Partial date coverage is reported in the projection summary.
- `npm run build` runs the regression suite through `prebuild`, including on the
  existing DigitalOcean automatic deployment configuration.
