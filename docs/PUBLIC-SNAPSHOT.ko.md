# 실제 항차 공개 스냅샷

사용자가 실제 항차를 공개 데모에 반영하도록 명시적으로 요청했다. 2026-09-14 17:15:08 UTC 조회한 Operational 항차 46건, 고유 선박 42척을 정적 사이트에 표시한다. 자동 갱신은 아니다.

공개 필드는 선박명, 연도/항차번호, 참조번호, OPR 상태, 순서대로 정리한 기항명, 등록 시작/종료 GMT 시각이다. API 내부 key/self, IMO, 회사별 API 주소, 재무 항목, 원문 보고, 인증정보는 공개 스냅샷에 포함하지 않는다. `data/` 원본은 Git에서 제외한다.

`src/live.js`가 현재 진입점이다. 과거 가상 데이터 모듈은 현재 번들에서 사용하지 않는다. 항차별 ID로 복수 항차를 유지하고 선박 수와 항차 수를 구분한다. 기간 판정은 스냅샷 조회시각을 기준으로 고정한다. 종료시각 경과 OPR 16건을 검토 대상으로 표시하며, 등록 기간 내 30건을 실제 항해 중이라고 확정하지 않는다.

등록 시작/종료는 `voyageStartDateGMT`와 `voyageEndDateGMT`다. 목적항 ETA, 실제 완료, 현재 위치로 재해석하지 않는다. 본선 보고 또는 AIS의 위치 검증이 없어 지도에 선박 마커를 표시하지 않는다. Outlook 대조 미연결을 각 화면에 표시한다.

로컬 원본에서 승인된 필드만 생성하는 명령은 `node scripts/prepare-public-snapshot.mjs`다. 새 스냅샷 공개는 별도 공개 범위 확인 후 수행한다. 키를 번들에 넣어 브라우저에서 Dataloy를 직접 조회하지 않는다.

검증: 테스트 14개 통과, production build 성공, 실제 항차 목록·복수 항차 검색·순서 있는 상세 기항을 브라우저에서 확인했다.
